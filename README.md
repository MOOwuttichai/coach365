# Coach 365

แอปมือถือ (PWA) สำหรับแผนเปลี่ยนตัวเอง 2 ปี (ปี 1 ลดไขมันจนลีน ไขมัน 10–15% → ปี 2 สร้างกล้าม แล้วตัดไขมันสั้นโชว์กล้าม) เริ่มวันที่ 1 = ศุกร์ 9 ต.ค. 2569 (วันก่อนเริ่มเป็นวันซ้อมมือ) แผนเต็มอยู่ใน `../แผน2ปี.md`

- **วันนี้:** เป้าก้าว หน้าต่าง IF ตารางวันนี้ (มีเวลาพักผ่อนรวม 3 ชม.) ตัวจับเวลานั่งสมาธิพร้อมจังหวะหายใจ บันทึกน้ำหนัก/รอบเอว/รอบคอ/เช็กลิสต์ กราฟน้ำหนักเทียบเส้นความเร็วที่ปลอดภัยและน้ำหนักเป้าที่ตั้ง
- **ไขมันในร่างกาย:** คำนวณจากส่วนสูง รอบเอว รอบคอ (สูตร US Navy) บอกน้ำหนักที่จะไขมัน 15/12/10% เตือนถ้าน้ำหนักเป้าต่ำจนต้องเสียกล้าม และให้ลดต่อทีละ 4 สัปดาห์ถ้ายังไม่ลีนพอก่อนเริ่มปี 2
- **แคลอรี่ปรับเอง:** เป้าคำนวณจากน้ำหนักเฉลี่ย 7 วัน ส่วนสูง อายุ (Mifflin-St Jeor × 1.45) และอัตราลด/เพิ่มของช่วง ทุกสัปดาห์ถ้าน้ำหนักเปลี่ยนนอกช่วงที่ควร แอปเสนอ ±100 kcal ให้กดยืนยัน มีสัปดาห์พักไดเอทท้ายเดือน 3, 6, 9
- **นอน / น้ำ:** กด "นอนแล้ว" ตอนเข้านอน + "ตื่นแล้ว" ตอนเช้า แอปคิดชั่วโมงนอนให้ (เป้า 7–8 ชม.) · น้ำ 32 มล./กก. นับเป็นแก้ว ลดตามน้ำหนัก
- **ตารางส่วนตัว:** วันทำงานตื่น 06:30 → สมาธิ → บุคลิก → ออกกำลังกาย 06:55 → อาบน้ำ → พัก 45 นาที 08:00–08:45 → ออกจากบ้าน · เสาร์–อาทิตย์ตื่น 07:30 · นอน 23:00
- **สแกนบาร์โค้ด:** ของสำเร็จรูป ดึงข้อมูลจาก Open Food Facts ถ้าไม่มีกรอกจากฉลากครั้งเดียวแอปจำไว้
- **สำรองอัตโนมัติ (APK):** วันละครั้งลง `Documents/Coach365` ลบแอปแล้วไฟล์ยังอยู่ กู้ด้วยปุ่มนำเข้า
- **อาหาร:** ถ่ายรูปอาหาร + AI (Gemini ค่าเริ่ม หรือ Claude) ประเมินแคลอรี่ (ใช้ API key ของคุณเอง) หรือเลือกเมนูร้าน/ชั่งวัตถุดิบเอง แผนอาหาร 7 วัน 2 ชุดสลับสัปดาห์ สูตรอาหาร 20 สูตรพร้อมปริมาณเป็นกรัม วิธีสั่งอาหารนอกบ้าน และรายการซื้อของ
- **เวท:** โปรแกรมตามเฟส (Full body A/B → Upper/Lower) รูปท่าจริง 18 ท่า บันทึกน้ำหนักที่ยก และ **ตรวจท่าด้วยกล้อง** (นับครั้ง วัดมุมข้อต่อ บอกจุดผิดเป็นเสียงภาษาไทย) + ตรวจบุคลิกท่ายืน (คอยื่น ไหล่ห่อ)
- **เงิน:** เป้าเงินเก็บ 100,000 บาท รายได้งานเสริม และ passive income เทียบเป้า 300 บาท/วัน
- **ตั้งค่า:** ข้อมูลร่างกาย (ส่วนสูง อายุ น้ำหนักเป้า ไขมันเป้า) แจ้งเตือนตามตาราง + สไตล์โค้ช (ด่า / ปลุกใจ / สุภาพ) + ทวงถ้ายังไม่ทำ ส่งออกเป็นไฟล์ปฏิทิน (.ics) ตั้ง AI และสำรองข้อมูล

ไม่มี build step เป็น HTML/CSS/JS ล้วน ข้อมูลเก็บในเครื่อง (`localStorage` + รูปอาหารใน IndexedDB)

## ความแม่นยำ (อ่านก่อนใช้)

- **แคลอรี่จากรูป:** ไม่มีระบบไหนแม่น 100% เพราะรูปมองไม่เห็นน้ำมัน น้ำตาล และน้ำหนักจริง AI มักคลาดเคลื่อน ±20–30% แอปจึงให้ช่วงต่ำสุด–สูงสุด และให้แก้ตัวเลขเองได้ ถ้าต้องการแม่นที่สุด ให้ใช้ตาชั่งดิจิทัลกับโหมด "ชั่งวัตถุดิบเอง" (คลาดเคลื่อนประมาณ ±5–10%) หรืออ่านค่าจากฉลาก
- **ตรวจท่า:** AI วัดมุมข้อต่อจากกล้อง 2 มิติ วางกล้องด้านข้าง สูงระดับเอว ห่าง 2–3 เมตร ใช้เป็นตัวช่วย ไม่แทนโค้ชจริง

## แจ้งเตือน

เว็บแอปตั้งเวลาแจ้งเตือนล่วงหน้าตอนปิดแอปไม่ได้ จึงมี 2 ชั้น:
1. **ในแอป:** เตือนตามเวลาขณะที่แอปเปิดหรือค้างอยู่เบื้องหลัง
2. **ปฏิทิน (แนะนำ):** แท็บตั้งค่า → ดาวน์โหลด .ics → เปิดด้วยปฏิทินมือถือ ถ้าใช้ Google Calendar ให้ตั้งการแจ้งเตือนเริ่มต้นของปฏิทินเป็น "ตอนเริ่มกิจกรรม"

**สไตล์โค้ช** (แท็บตั้งค่า ค่าเริ่ม = ด่า): หัวข้อแจ้งเตือนเป็นคำพูดโค้ชที่สุ่มใหม่ทุกวัน เนื้อความยังบอกสิ่งที่ต้องทำเหมือนเดิม ด่าที่พฤติกรรม ไม่ด่าที่ตัวคน ใส่ "ทำไปเพื่ออะไร" ไว้ โค้ชจะเอามาทวงตอนขี้เกียจ · สไตล์ด่าจะแซะบนการ์ดหลักด้วยถ้าช้ากว่าเวลาเกิน 15 นาที

**ทวงถ้ายังไม่ทำ** (แอป Android ตั้งล่วงหน้า 7 วัน · เว็บเด้งเฉพาะตอนแอปเปิดอยู่) ทำในแอปแล้ว = ยกเลิกให้เอง:

| เวลา | ถ้ายังไม่ได้ |
|---|---|
| ตื่น +20 นาที | กด "ตื่นแล้ว" หรือชั่งน้ำหนัก |
| ออกกำลังกาย +15 และ +35 นาที | กดเริ่มเวท / HIIT / เดินแล้ว |
| 17:00 | บันทึกอาหารสักมื้อ |
| 22:20 | ใส่ก้าววันนี้ |
| 23:20 | กด "นอนแล้ว" |
| ไม่เปิดแอป 1, 2, 3, 5, 7 วัน | เปิดแอป (เปิดแล้วเลื่อนออกไปเอง) |

ก่อนวันเริ่มมีนับถอยหลัง 21:00 ทุกวัน และคืนก่อนวันแรกทวงให้นอน 23:20

## แอป Android (APK)

ทุกครั้งที่ push ขึ้น `main` GitHub Actions จะสร้างไฟล์ APK ให้อัตโนมัติ ดาวน์โหลดได้ที่หน้า **Releases → "Coach 365 Android (ล่าสุด)" → Coach365.apk**

- แอปเป็น Capacitor shell ที่โหลดหน้าเว็บจาก GitHub Pages จึง**อัปเดตเองทุกครั้งที่มีเวอร์ชันใหม่** ไม่ต้องลง APK ซ้ำ
- **แจ้งเตือนตามเวลาจริงแม้ปิดแอป** ผ่าน Local Notifications (ตั้งให้เองตอนเปิดแอป วันละครั้ง และทุกครั้งที่เปลี่ยนการตั้งค่าแจ้งเตือน)
- กล้อง (ตรวจท่า) และการสั่นใช้ได้
- APK เป็น debug build สำหรับติดตั้งเอง ไม่ได้ขึ้น Play Store ครั้งแรกมือถือจะถามให้อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก"
- **วิดเจ็ตหน้าจอโฮม** (4×3 ปรับขนาดได้) มีปุ่ม 💧+1 แก้ว และ 🔒 ปิดครัว กดได้โดยไม่ต้องเปิดแอป: วันที่/ช่วง สิ่งที่ต้องทำต่อตามเวลา โปรแกรมวันนี้ หน้าต่างกิน แคลอรี่ โปรตีน ก้าว แตะแต่ละแถวเพื่อเปิดแท็บนั้น หน้าเว็บส่งแผน 14 วันข้างหน้าไว้ให้ ปิดแอปหลายวันวิดเจ็ตก็ยังบอกโปรแกรมได้ (โค้ด native อยู่ใน `android-src/` workflow ก๊อปไปใส่โปรเจกต์ Android ตอน build)
- ถ้าอยากลงเอง: `npm install && npx cap add android && npx cap sync && cd android && ./gradlew assembleDebug` (แล้วก๊อป `android-src/` ตามขั้น "Home-screen widget" ใน `.github/workflows/android.yml`)

### Honor / MagicOS (เช่น Honor X9d)

MagicOS ปิดแอปเบื้องหลังเก่งมาก ถ้าไม่ตั้ง แจ้งเตือนจะเงียบ:
1. ตั้งค่า → แอป → Coach 365 → **การแจ้งเตือน** เปิดทั้งหมด
2. ตั้งค่า → แบตเตอรี่ → **การเปิดแอป** (App launch) → Coach 365 → ปิด "จัดการอัตโนมัติ" แล้วเปิดครบ 3 ช่อง (เปิดอัตโนมัติ / เปิดรอง / ทำงานเบื้องหลัง)
3. ตั้งค่า → แอป → Coach 365 → สิทธิ์ → **นาฬิกาปลุกและการเตือน** อนุญาต
4. วิดเจ็ต: จีบนิ้วบนหน้าโฮม (หรือกดค้างที่ว่าง) → วิดเจ็ต → Coach 365 → ลากไปวาง
